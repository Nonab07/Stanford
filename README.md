# Учебный центр «STANFORD» — Официальный сайт (Landing Page)

Современный минималистичный одностраничный сайт учебного центра **«Stanford»** с полноценной поддержкой:
- **3 языков**: Русский (`ru`), Английский (`en`), Узбекский (`uz`);
- **Автоопределения языка устройства** (по умолчанию ставится язык системы, если язык системы не русский и не узбекский — по умолчанию включается `en`);
- **Темной (`Dark Mode`) и светлой (`Light Mode`)** тем оформления;
- Фирменных оранжево-янтарных акцентов (`#FF6B00`, `#FFB800`).

---

## 🌐 Мультиязычность (i18n: RU, EN, UZ)

### Логика выбора языка по умолчанию:
1. **Сохраненный выбор**: Если пользователь ранее выбирал язык, сайт восстанавливает его из `localStorage` (`stanford_lang`).
2. **Язык устройства / системы (`navigator.language` / `navigator.languages`)**:
   - Если язык устройства **русский** (`ru`) ➔ включается **Русский (`ru`)**;
   - Если язык устройства **узбекский** (`uz`) ➔ включается **O'zbekcha (`uz`)**;
   - Если язык устройства **любой другой** (английский, казахский, немецкий, турецкий и т.д.) ➔ по умолчанию включается **English (`en`)**!
3. **Интерактивный Slidebar переключения языков**:
   - **На ПК / десктопе**: компактная кнопка с кодом языка и шевроном; при клике плавно **спускается вниз** стильное меню выбора с флагами стран (`🇷🇺 Русский`, `🇬🇧 English`, `🇺🇿 O'zbekcha`), индикатором активности и галочками `✓`.
   - **В мобильной версии**: удобный раскрывающийся аккордеон-слайдер в навигационном меню.
   - Меню автоматически закрывается при выборе языка, клике вне панели или нажатии `Esc`.

### Переведено всё содержимое сайта:

- Все 3 курса (Английский, Биология и Химия, Математика);

## 🎨 Темы оформления (Dark / Light)
- **Темная тема (Dark Mode)**: глубокий черный `#0A0A0A` и графитовый `#141414`.
- **Светлая тема (Light Mode)**: чистый фон `#FAFAFA` и белоснежные карточки `#FFFFFF` с мягкими тенями.
- **Акценты**: Яркий оранжевый `#FF6B00` и янтарный `#FFB800` / `#D97706`.
- **Anti-Flicker**: В `<head>` встроен скрипт, устраняющий мерцание темы и языка при обновлении страницы.
